# 🧳 Packmate 行李清單

出國行李清單網頁 App：設定出發日期與幾天幾夜後，依分類勾選要帶的東西，出發前一天和當天會提醒還沒打包的物品。

## 功能
- 設定目的地、出發日期、幾天幾夜與旅行情境（海島、出差、寒冷地區、登山、帶小孩）
- 14 個分類，區分「必帶」與「可帶可不帶」，衣物件數依天數自動計算
- 出門前檢查清單、託運與安檢小提醒
- 紀錄存在使用者自己的瀏覽器，不需註冊帳號
